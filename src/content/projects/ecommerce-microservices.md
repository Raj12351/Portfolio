## Overview

Before moving into GenAI, I developed and enhanced **high-scale REST microservices** for enterprise clients on the Skava e-commerce platform.

## What I worked on

- Designing and extending REST APIs used by storefronts.
- Building features across services in Java and Spring Boot.
- Working with MySQL for persistence and Redis for caching under production traffic.

## What carried over

This backend foundation, covering API design, caching, and reliability under load, is what makes GenAI systems production-ready. A RAG app is still a backend service.
